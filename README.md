# ExitKit AI

Демо передачи дел из TXT, Markdown, текстовых PDF и DOCX. Streamlit собирает
проекты, задачи, риски, контакты и вопросы; отчёт доступен в PDF и Markdown.

## Модель и данные

Используется бесплатный маршрутизатор `openrouter/free` через OpenRouter API.
Платного резервного маршрута нет. Конкретная модель выбирается провайдером,
поэтому скорость, качество и доступность зависят от бесплатной квоты.
Каждая часть документа — отдельный запрос, повтор русского ответа расходует
дополнительный запрос. Общий серверный ключ означает общую квоту посетителей.

Текст отправляется OpenRouter и выбранному провайдеру только после согласия
пользователя. Для публичного демо используйте тестовые материалы без секретов
и персональных данных. Всегда сверяйте отчёт с исходными документами.

## Локальный запуск

Требуется Python 3.11+:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

Настройте серверную переменную `OPENROUTER_API_KEY` либо сохраните ключ
в локальном `.streamlit/secrets.toml`:

```toml
OPENROUTER_API_KEY = "ваш_ключ"
```

Не коммитьте файл Secrets и не вводите общий ключ в интерфейсе приложения.
Загрузите `sample_data/handover_example.txt` для проверки. Без ключа можно
посмотреть интерфейс, но анализ заблокирован.

## Streamlit Community Cloud

1. Создайте приложение из этого GitHub-репозитория, ветка `main`.
2. Main file path: `app.py`. Выберите Python 3.12 в Advanced settings.
3. В Secrets добавьте `OPENROUTER_API_KEY = "ваш_ключ"` в формате TOML.
4. Выполните Deploy. Ключ хранится в настройках облака, не в репозитории.

Python-зависимости — `requirements.txt`; системный шрифт PDF — `packages.txt`.
Тема и ограничение загрузки задаются в `.streamlit/config.toml`.

## Ограничения

- До 4 МБ на файл, 60 000 извлечённых символов на файл и 20 частей на запуск.
- OCR нет; таблицы DOCX читаются как текст, изображения не анализируются.
- Документы и отчёт живут в памяти сессии; при перезапуске облака могут потеряться.
- Ошибки квоты, отказа или обрезанного ответа показываются пользователю;
  приложение не подменяет их фиктивными результатами.
- После повторного английского ответа неподходящие поля удаляются с
  предупреждением в вопросах отчёта. Проверяйте полноту результата.
